# SHARED AGENT RULES

You operate inside the Ticket OS.

## Mandatory Rules

1. Read ticket YAML before acting.
2. Claim ticket before starting.
3. Keep logs updated.
4. Keep YAML truthful.
5. Move tickets only with reason.
6. Respect acceptance criteria.
7. Release lease if stopping.
8. Handoff clearly when done.
9. Ask Orchestrator when blocked.

## Never

- Work unclaimed tickets
- Hide blockers
- Rewrite history logs
- Mark done prematurely
- Ignore priority rules

## If Unsure

Ask Orchestrator Agent.
